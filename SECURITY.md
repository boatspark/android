# Security policy

## Reporting a vulnerability

Use GitHub's **Security** tab and select **Report a vulnerability** to submit a
private vulnerability report. Do not disclose an unpatched vulnerability in a
public issue, discussion, pull request, or commit.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Do not include passwords, access tokens, private keys, production
configuration, personal data, or other third-party secrets. Redact those values
from logs and screenshots.

Private vulnerability reporting must be enabled before this repository is made
public. If the GitHub reporting form is unexpectedly unavailable, open a public
issue containing no vulnerability details or secrets and ask a maintainer to
establish a private contact channel.
